Headshots for the People page.

Square JPGs, 640 x 640 pixels, named after the person using lowercase and
hyphens, for example: ishita-dasgupta.jpg

The filename is referenced by the "photo" field in data/people.json, as
assets/img/people/ishita-dasgupta.jpg

Anyone without a photo shows their initials in a circle of the same size
instead, so the page still looks even. Leave their "photo" field empty.
